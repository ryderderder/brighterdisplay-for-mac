# Security

This experimental app can intercept brightness events and change a display's gamma table. Treat event routing, ownership/restoration, permissions, update authenticity and packaging as security-sensitive code.

Only the current preview receives fixes; no long-term support or response-time guarantee is offered. Update support is manual in 0.3.0.

For an ordinary bug, open an issue with a minimal reproduction and no secrets, personal logs or unrelated data. For a suspected vulnerability, first check the repository Security tab for private vulnerability reporting. If it is unavailable, open a minimal issue asking for a private reporting channel without disclosing the exploit, credentials, personal data or sensitive details. Do not post those details publicly.

Never commit signing keys, certificates containing private keys, access tokens, local preferences or generated diagnostic logs. No app or release workflow should weaken macOS protections to make installation or updates easier.
